# IEEE paper

`ieee_paper.tex` — IEEE conference format (`IEEEtran`), 8 pages including
references.

## Build

```bash
cd paper
pdflatex ieee_paper && pdflatex ieee_paper   # run twice for cross-references
```

Verified with MiKTeX (pdfTeX): 0 overfull boxes, 0 undefined references,
12 of 12 bibliography entries cited.

The bibliography is inline (`thebibliography`) so the document compiles with
no external `.bib` or `.bst` file. To switch to BibTeX for submission,
replace that block with `\bibliographystyle{IEEEtran}\bibliography{refs}`.

For the IEEE **journal** format instead of conference, change the class
options to `[journal]{IEEEtran}`.

## Before submission

- **Fill in the author block.** It is a clearly marked placeholder; author
  name, affiliation and email were left unfilled rather than guessed. The same
  applies to `CITATION.cff` in the repository root.
- Confirm the venue's page limit — the paper is 8 pages with two full-width
  figures, which can be trimmed to 6 by moving Figs. 1 and 4 to a supplement.
- Ten of the thirteen surveyed prior studies are coded from an attributed
  comparison table rather than independently verified (stated in the paper and
  flagged in `data/literature/prior_work.csv`). Hand-verify them if the venue
  expects a systematic review standard.

## Provenance of every number

Each table in the `.tex` carries a comment naming the CSV it came from, all
under `reports/tables/`. Nothing was transcribed by hand from prose. The
figures are copied unmodified from `reports/figures/`:

| Figure | Source | Generated by |
|---|---|---|
| Fig. 1 spectrum | `fig_r12_spectrum_effect.pdf` | `scripts/04_evaluate.py` |
| Fig. 2 provenance null | `fig_r15_provenance_null.pdf` | `scripts/17_provenance_figure.py` |
| Fig. 3 binning cost | `fig_r14_binning_cost.pdf` | `scripts/11_continuous_recovery.py` |
| Fig. 4 EBM shapes | `fig_r13_ebm_shapes.pdf` | `scripts/10_ebm_shapes.py` |

To regenerate the figures after a pipeline change, re-run the stage above and
re-copy the PDF into `paper/figures/`.
